# Green API Telegram Messenger

Тестовое задание на позицию Frontend Developer (React)

## Стек

* React
* TypeScript
* Vite
* Feature-Sliced Design (FSD)
* Green API
* Telegram API

## Запуск

```bash
npm install
npm run dev
```

## Функциональность

* подключение к Green API по `idInstance` и `apiTokenInstance`
* создание чата по номеру телефона
* отправка текстовых сообщений
* получение входящих сообщений
* отображение истории сообщений
* обработка ошибок API

## API

Для работы с сообщениями используется Telegram API через Green API

Документация: https://green-api.com/telegram

## Примечание

Проект реализует аналог интерфейса мессенджера на основе Telegram API, предусмотренного тестовым заданием в качестве альтернативы MAX
